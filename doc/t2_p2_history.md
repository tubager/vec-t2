## 2. 优化过程（六段范式）

### 2.1 基线与几何第一刀（09-05 → 09-07）

从 `copy_last`（约 51）只改尺度到 `scale_copy`（TSR 拉满），再 `shift_scale` 加全局 Δ：表达涨、**variogram 砸穿**（胚胎 50→40、心脏 52→34）。`full` 各向异性 n=3000 把胚胎推到 61.93。

关键分叉：成对 mix 真细胞、不加 Δ → 胚胎 **65.12**（CSS 41.5→66.9），但两团点云把 ODS 砸到 40。接着 OT lerp 表达 **62.46**（真共变被冲淡）。结论：**不要 lerp 表达，要真细胞 + 一团几何。**

### 2.2 OT-place：真细胞放置（09-07 → 09-08）

簇内 Hungarian 把左右真细胞贴到左锚云：

- 胚胎 OT-place w=1/3 → **66.18**，TPS 形变左云 → **66.32**，n=5000+去重 → **66.41**
- 心脏 OT-place w=0.5 → 65.31；**w=0.25** → **68.33**（NFS 72.1）。w=0.20 回退。胚胎改 w 两侧都亏，锁 1/3。

心脏 TPS / `--geom-src right` / 叠云 mix 全部砸 d2 或 NFS。外推 `scale_copy` n=5000 β=0.268 → 54.15。

### 2.3 几何穷尽（09-09 → 09-11）

试图用占位/FOV/occ/trim/加 n 追第一名的 shape：

| 尝试 | 结果 | 教训 |
|------|------|------|
| 心脏 crop-keep FOV | **58.40** | 丢外周 = 丢细胞型；d2 30；本地 E8.75 代理不可迁移 |
| 外推只加 n | 53.24 | NFS 不涨 |
| 心脏加 n 10k/17k | 67.67 / 67.85 | NFS 在 n=5000 两侧下坡 |
| 外推 G0 真细胞重采 | **54.66** | 此后永锁 |
| 外推组成趋势 | 51.49 | 组成位移同时毁 X 与点云 |

Panel OT-CFM 在两条真值窗上 variogram 炸 4–6×，`flow.use` 关。

### 2.4 冻云拧 X（09-12 → 09-14）

胚胎：slice/band 真细胞截断 → 原生几何 ODS 崩（01=66.22）。**冻 xyz、只换 X**：

### 2.5 原生出生再开（09-15）

假设顶队在邻域里选中期表达、细胞带着 X 出生在目标几何。comp×TPS 票 130 留出过门、板上 **65.63 / ODS 53.6 / nocc 213**。留出 ODS≈0.90 不迁移。关 comptps。外推 0 格。

## 7. 反复验证过的机制

1. **真细胞混库才能保住 variogram。** lerp、全局 Δ、独立生成、PCA 插值都会打碎共表达。
2. **表达必须和坐标一起出生。** 拆对（右 X 贴左 xyz、随机贴点）伤 NFS；OT 配对能收回一部分。Hungarian 重排是在**同一多重集**上收配对税，de/mmd 集合不变。
3. **两期真细胞的任何插值/运输，留出窗都像 E7.25，近窗板要 E7.5。** 留出 de 上升或 NFS/var「大赢」→ 板上崩（10、206、209）。双门对这条 X 族是反指标。
4. **分簇曲率只在胚胎 α=1 动过 de，心脏复制失败。** 09a→194 只换配对，de 零变化。201 全局 Δμ：簇间相对 DE 不变。**210** 分簇 α=1：de 59.5→60.2。**211** 同算子 α=2.5 上 196：de **仍 63.6**，dir −0.6，var −1.0。本地 de vs E8.75 0.696→0.761 是反指标（更像右锚，板上 E8.5 不买）。精确锁住 63.6 = top-K 没进真 DE 集，更小的 α=1 是同一方向的更弱旋转，不交。关心脏曲率。换细胞则 NFS/dir 先死。
5. **本地几何代理不可迁移。** crop 本地 73 → 线上 58.40；occ/trim 的 d2 排序反转；留出 ODS 0.90 ≠ 板上 53.6。
6. **n=5000 是 NFS 峰**（双侧插值）。再密再稀都掉。
7. **行序噪声 ±0.6 总分。** 小于 2 skill 且落在 mmd/var/NFS/d2 上的单格，不要当机制。
8. **心脏 W2 不作心脏-X 出门。** 外推表达永锁。禁止 E7.5 GT 泄漏。

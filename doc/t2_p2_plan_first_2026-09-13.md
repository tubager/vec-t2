## 1. 现役范式为什么到顶

现役 = 左右锚 **真细胞** Bernoulli 抽样 + OT 配对放置 +（可选）TPS / span-trim / 坐标移植。

已证伪的「在同一范式里拧」：

| 族 | 结果 |
|----|------|
| 全局表达 band / keep 网格 | de↑ 但原生 ODS 崩；冻到全图坐标 → NFS 税 |
| 空间分层 keep=0.25 | ODS 修好，mmd 税 16% 卡 AND |
| bandX 换 spatial 云 | 只有 k0.4 b6 过门；更稀云砸 ODS |
| `--ot-w` 左偏冻 xyz | 留出 mmd/var 大胜 → 板上反输（67.34） |
| 轨迹/组成/RNA/重排耦合 | 离线否 |
| panel OT-CFM（旧训法） | variogram 炸；提交关 |
| 心脏 crop-keep FOV | 本地 intermediate 73 → 线上 **58.40**（组成+径向崩） |
| 外推 Δ / 加 n / 轴比 / 组成趋势 | 全否；锁 G0 |

**机制一句话：** 混两个真实阶段，永远得不到「只属于目标时刻」的局部邻域统计。ceiling NFS raw≈0.008，我们≈0.07–0.09；全局 mmd 只差 ~3×，**洞在局部，不在全局平均**。Hungarian 把中期 X 贴到全胚坐标，是在付顶队大概没付的税。

## 2. 新范式：三层生成（不是再优化 OT-place）

目标产物：每个细胞是 **(x_gene, xyz)**，其中  
1. **基因向量** 落在目标阶段流形上（真共表达，不是两期平均）；  
2. **坐标** 占目标阶段几何（不是缩尺左锚）；  
3. **二者原生耦合**（细胞在自己该在的体素里出生，禁止事后全局重贴）。

### 2.1 Pillar A — 条件流 / 扩散生成 X（主杠杆）

**做什么（相对旧 flow 的改法）：**

- 条件：工作簇 + 连续时间 `t` +（可选）局部空间 token（见 B）。  
- 训练目标：在 **同一簇内** 学 `p(X | t, cluster)`，用 OT-CFM 或 rectified flow；**禁止**用全局 panel 无条件生成后靠 OT 硬贴。  
- 数据：胚胎用 E6.75/E7.25/E8.0；心脏用 E8.25/E8.75/E9.5。插值目标用 `t*` 采样；验证用留出窗（胚胎假 E7.25、心脏假 E8.75）。  
- **关键验收（不过门不开 `--use-flow`）：**

| 窗 | 相对现役 OT-place | 硬门槛 |
|----|-------------------|--------|
| 胚胎 E6.75+E8.0→E7.25 | NFS **≤ 0.045**（现役 band 冻坐标 ~0.07） | mmd ≤ mix×1.10；variogram **不得** 4× 爆炸 |
| 同上 | de ≥ 0.32 | ODS ≥ mix−0.02（若用原生几何） |
| 心脏 W2 E8.25+E9.5→E8.75 | NFS ≤ 现役 0.070；de ≥ 0.63 | variogram 不差于现役 14% |

旧 flow 失败模式是「全局残差 + 弱更新 → CSS 崩」。新训法必须：**每 epoch 多簇、大 batch OT pairing、显式共变正则（或直接在 PCA-32 上匹配二阶矩）**。

若 1–2 天训不出过门权重：**降级为簇内高斯 / VAE 残差**（在 PCA-32 上对 `t` 条件），仍比 Bernoulli 混真细胞更接近目标流形；同样过上述门。

### 2.2 Pillar B — 空间条件：邻域内切，而不是全局切

顶队假设（账本 §16–§17）：**在每个空间邻域里选中期表达，占据仍像全图。**

实现候选（按风险升序）：

1. **分层 band（已实现）+ 更宽 keep（0.35–0.45）+ 调箱**  
   - 目标：mmd 税 ≤14% 且 de 接近全局 band。  
   - 过门才交原生几何；不过门 → 不交、不冻到 04 滥竽充数。  
2. **kNN 局部进度**  
   - 对每个左锚细胞，在空间 kNN 内算表达进度分位，只保留局部 mid-band；配额按全局占据模板。  
   - 比硬体素箱更贴「邻域内切」。  
3. **空间 token 条件生成（与 A 合流）**  
   - 生成时条件于「该体素的左右锚局部 pb」；采样出的细胞直接落在该体素。  
   - 这是冲 73.8 的正统形态；A 不过门则 B 只做 1–2。

### 2.3 Pillar C — 几何：目标期点云先验，禁止拆耦合的后处理

- 胚胎：继续 TPS 左云形变到目标尺度（已证明救 ODS）；RMS 锁 198.24。  
- 心脏：**不要再 crop-keep**。改走「生成时按簇密度生长 / 从右锚几何继承外周」——细胞带着自己的 X 出生在目标几何上，而不是拒绝采样后 OT 搬进核。  
- **禁止**作为主路径：全局 Hungarian 重贴、整云 span-trim 追第一、离线搜行序赌 d2。  
- 允许：生成后 **局部** 微搬（已有 span-trim 量级、|d|/RMS≪0.01）仅用于 nocc 校准，且须 NFS 代理不变。

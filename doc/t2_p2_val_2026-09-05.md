## 3. 判定（给后面的提交用）

1. **Panel / 格式：** 胚胎 498 列通过。缺 `spatial_3D` 或交 500 基因胚胎会拒，本次无此问题。
2. **几何：** 各向同性缩放只动 TSR，两插值 + 外推均成立。外推不要用 8.75→9.5 斜率（会到 RMS≈598）。
3. **表达 shift：** 两插值净赚，留下当新地板。外推先保持「放大后的 copy」。
4. **`full`（组成 + 按簇放点）：** 本地胚胎代理上 MMD/CSS/NFS 差于拷贝；线上 CSS 已是弱项 → **胚胎先不上**。心脏插值类型对齐、本地生长诊断 `full` 很强 → **下一份只试心脏插值**。
5. **Flow / TPS：** 继续关。本地 OT-CFM 未过 MMD 门。

过门才换最好：新文件总分必须高于上表；心脏插值 `full` 还要看 `variogram` 会不会从 33.6 再往下掉（掉到 ~25 就回退 `shift_scale`）。

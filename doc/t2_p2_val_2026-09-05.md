### 12.2 §11.6 的 δ 方案：可辨识性算错了，且被 W2 门否掉

`log m_{S,k,g} = a_{k,g} + b_{k,g} t_S + δ_{S,g}` 的设计矩阵有**两维**零空间，不是一维：

1. `δ_S += c`，`a_k −= c`（常数规范）；
2. `δ_S += q·t_S`，`b_k −= q`（**时间线性规范**）。

所以 3 期 × K 簇 = 3K 观测、秩 2K+1，**只有曲率这一个组合可辨识**：`ρ_g = δ_M − (1−θ)δ_A − θδ_B`，θ=(t_M−t_A)/(t_B−t_A)。§11.6 想拿的 `δ_M − δ_A` **不可辨识**（它与簇时钟斜率 b_k 完全混淆）。固定两个规范写成 `δ(t)=γ_g(t−t_A)(t−t_B)` 后预测才是规范不变的。

曲率本身是真的（`scripts/diagnostics/25_delta_ident.py`，9 个共有簇）：`ρ_g` sd 0.384 log 单位、SE 0.139、簇对半分相关 0.595；**1 个自由度把加权残差 MSE 从 0.0486 砍到 0.0266（−45.4%）**。

### 14.1 被排名的量是 `|scale_log_ratio|`，不是签名值；胚胎真值 RMS = 198.24，不是 200

`common/core_metrics.py::skill()` 的实现是

```
d_floor = |ceiling - floor|
d       = (value - ceiling) if lower_is_better else (ceiling - value)
skill   = min(d_floor / (d_floor + d), 1.0)
```

`scale_log_ratio` 是**签名**量（理想 0），所以 `value - ceiling` 与 `ceiling - value` 两种写法
都只在天花板一侧单调。用官方 `index.json` 的地板/天花板（§1.5 表）配板上**四个自读点**联立，
唯一自洽的读法是把排名量取绝对值：

```
v = |log(RMS_pred / RMS_true)| ,  D = ||ceiling| - |floor|| ,
skill = D / (D + v - |ceiling|) ,  v <= |ceiling| 时 clip 到 1.0
```

| 榜 | 文件 | RMS | 预测 skill | 板上 | 残差 |
|----|------|-----|-----------|------|------|
| 胚胎插值 | `scale_copy_E75`（实测 192.0575，不是文档里写的「192」） | 192.0575 | 91.894 | 91.9 | 0.006 |
| 胚胎插值 | 全部 `rms200` 文件 | 200.0000 | 98.795 | 98.8 | 0.005 |
| 心脏插值 | `scale_copy_E85` | 277.13 | 82.500 | 82.5 | 0.000 |
| 心脏插值 | 现役 | 255.00 | 100.000 | 100.0 | 0.000 |

两个签名模型直接被这两点否掉：`d = value − ceiling` 在胚胎两点上给出真值 RMS 185.8 与 198.18，
`d = ceiling − value` 给出 196.3 与 199.70，**自相矛盾**；绝对值模型给 198.268 与 198.217，一致。

- **胚胎真值 RMS = 198.233 ~ 198.258**（两点在显示精度 ±0.05 skill 内的区间交集）。
  100.0 的 clip 窗口 = `T·[e^−0.0053, e^+0.0053]`，稳健区间 **[197.210, 199.286]**，中心 198.245。
  现役 RMS 200 落在窗口**外**（v = 0.00897 > 0.0053），所以只有 98.8 —— 不是「已经拧到头」。
- **心脏真值 RMS = 256.07**（277.13→82.5 单点解，且与 255→100.0 相容），窗口 [253.04, 259.14]，
  现役 255 在内 → 已 100.0，**心脏坐标不要缩放**。顺带修正 §11/§12 引用的
  「官方 docstring 表 E8.5 RMS 254.6」：那是**发布期**的值，验证榜真值是留出子样，实测反演 256.07。
- **外推真值 RMS = 437.92**（= 官方 E9.5 RMS 335.2 × e^0.268，即地板反演），现役 437.917 在内 → 100.0，不要动。
- 地板反演在心脏上交叉验证成功：官方地板 +0.3284 ⇒ copy_last RMS = 256.07·e^0.3284 = **355.63**，
  与 `size_fidelity` docstring 表里的 E8.25 = **355.6** 逐位吻合（我们本地量 `data/E8.25_late.h5ad`
  的 `spatial_3D` 是 354.13，差 0.4%，说明官方表用的不是这份文件的全量）。
  胚胎地板 −0.3063 ⇒ copy_last RMS = 145.94，本地 E7.25 量到 147.287，差 0.9% —— 同量级，
  所以**地板反演的 T 只能当交叉验证，不能当主解**（主解是上面那四点的联立）。

> `scripts/25_rescale_rms.py` 的 docstring 写「skill is clipped at 1.0 once rms_pred <= rms_true，
> 落在真值下方就是单向无风险收益」——**这是错的**，被 RMS 192.0575 < T = 198.24 却只得 91.9 直接证伪。
> 正确说法：clip 窗口是**双侧**的 `T·[e^−|ceiling|, e^+|ceiling|]`，胚胎只有 ±0.53% 宽。
> 这也是 v1 队列把目标定成 199.2 的错误来源：199.2 距窗口上边缘只剩 0.07（0.034%），
> 而 198.24 是窗口中心，两侧各留 ±1.04。**队列里的胚胎两格已按 198.24 重建。**

### 14.2 本地代理 → 板上的传递率：ODS 0.95，d2 **−1.30**（反向）

§9 的心脏 span-trim 是全部提交史上唯一一个「X 逐字节冻结、只动坐标、且有板上读数」的对照，
所以它能一次性标定两个形状项的传递率（板上原始值由 14.1 的 skill 反演式解出）：

| | 本地 Δ（对三锚点均值） | 板上 Δ（原始单位） | 传递率 |
|---|---|---|---|
| `occupancy_dice` | **+0.041220** | **+0.039080** | **0.95** |
| `d2_shape` | **−0.003026**（变好） | **+0.003919**（变差） | **−1.30** |

两条结论，方向相反：

1. **ODS 可以离线定量预测。** 传递率 0.95 ≈ 1，所以「本地对三个锚点一致改善」就是板上改善。
2. **d2 不能离线预测，而且反号。** §9 当时写「代理的 d2 排序再次不可迁移」，现在有了斜率：
   本地每改善 1 单位，板上恶化 1.3 单位。这同时**关掉**了「离线搜一个更好的行序去压 d2」这条线。
   证据链是闭合的：A（09-08 w0.5）与现役 E 共享同一个坐标点集，A 的本地 d2 对三个心脏锚点
   **全部更差**（0.016016 / 0.059103 / 0.013816 vs 0.014509 / 0.057844 / 0.013077），
   板上却拿到三点里最高的 d2 72.6（E 69.7）。

d2 的行序依赖来自 `d2_distance` 用 `rng(0).integers(0, n, 200000)` 抽**下标对**：点集固定时，
20 万条距离仍是随 20 万次抽样波动的经验分布。三个同点集读点反演成原始 d2 是
**0.014185（A）/ 0.015333（D）/ 0.015714（E）**，全距 0.001529 ⇒ 抽样 sd ≈ 0.0009，
而心脏 d2 的 `D = 0.02667` ⇒ **1 个抽样 sd ≈ 1.7 总分 skill ≈ 0.43 总分**。
这就是 §11.5「±0.6 总分行序噪声」的形状项来源，也说明 A 已经比三点均值低约 1 个 sd：
再往下压的无真值目标（让 20 万对样本代表自身完整距离分布）理论上界只有 ~+1.7 skill，
却要放弃 A 已测的 ODS 46.8（陪集重抽 ±1.65 skill）⇒ 期望值近零。**不做。**

**NFS 不 count-match ⇒ 密度必须按「满 n 对满 n」对齐。** 用轮廓不变量 `K = NN15·n^(1/3)/RMS`（与 n 无关）反解真值密度：

| 榜 | 真值 NN15 预测区间 | 线上现在（满 n） | 候选（满 n） | 候选/真值 |

### 1.1 距离第一名（68.93）的逐项缺口

官方 `common/core_metrics.py::skill` 是**双曲**映射，不是线性：
`skill = D/(D+d)`，`d` = 与天花板的距离，`D` = |天花板 − 地板| → 天花板 100、地板 50、比地板更差平滑压向 0。
用 TSR 验证（它是唯一知道原始值的项，天花板 = 原始 0）：三榜地板原始 TSR = +0.328 / −0.306 / −0.268 → 预测地板 skill 50.0/50.0/50.0，线上实测 **50.5 / 50.8 / 49.9** ✓；我们锁 RMS 后原始 ≈0 → **100** ✓。

|------|------|--------------------|----------------|----------------|
| `de_score` | 12.5% | 63.0 | 57.0 | **45.8** |
| `de_direction` | 12.5% | ~70.1（由表达题组反推） | 70.2 | 50.9 |
| `mmd_u` | 12.5% | 69.0 | 69.0 | 49.5 |
| `variogram` | 12.5% | 61.1 | 67.5 | 49.4 |
| `d2_shape` | 8.33% | 63.6 | 55.7 | 44.1 |
| `occupancy_dice` | 8.33% | **45.3** | 56.3 | 55.0 |
| `scale_log_ratio` | 8.33% | 100 | 98.8 | 100 |
| `neighborhood_mmd` | 25% | 72.1 | 62.7 | **51.0** |
| **第一名** | | **73.4**（−5.1） | **73.6**（−7.3） | **59.8**（−5.7） |

三条从映射本身得到的结论：

1. 记 `x = (1−s)/s`（离天花板还有几个「地板间距」）。心脏 ODS 45.3 → **x = 1.21，比地板还差 1.2 个地板间距**；外推的表达/状态四项 x = 0.96–1.18，**全部趴在地板上**（因为我们交的是 E9.5 的逐字拷贝）。

3. 胚胎 TSR 98.8 → x = 0.012 → **真值 RMS = 200 ± 0.4%**。这项只剩 +0.1 总分，别再拧。

## 2. 官方评分器告诉我们的机制

源码在 `.venv/lib/python3.13/site-packages/`：`T2/metrics_v2.py`、`common/shape_metrics.py`、`common/core_metrics.py`、`T2/metrics.py`。

| 指标 | 实现要点 | 我们能动的旋钮 |
|------|----------|----------------|
| `neighborhood_mmd` | k=15 kNN **建在提交的全部细胞上**，取邻域 pseudobulk，再抽 2000 个做无偏 MMD | **`n`**（决定邻域半径）、`(X,xyz)` 配对 |
| `occupancy_dice` | 两边都子样到 `min(n_pred, n_true)`（`_match_n`），各自 RMS 归一，16³ 网格 ±3 RMS 取占据体素 Dice | **FOV 截**（区域对齐）、去重（**不是 `n`**：已 count-matched） |
| `d2_shape` | 各抽 20 万对点，距离除以自身 RMS，两条距离分布做 1-D Wasserstein | 轴比、FOV 截（**与 n 无关**） |
| `mmd_u` | PCA-30 **只在真值上拟合**，各抽 2000 细胞，5 个带宽的无偏 RBF-MMD | 真细胞（已锁） |
| `variogram` | 各抽 1500 细胞、2 万对基因，比 `E|x_i−x_j|^0.5` | 真细胞（已锁） |
| `scale_log_ratio` | `log(RMS_pred/RMS_true)`，签名版 | 已锁 200 / 255 / 438 |
| `size_fidelity` | RMS 比 **×** 4000 子样中位 NN 比的折叠均值 | **未上榜**（见 §5 风险） |
| `count_log_ratio` | `log(n_pred/n_true)` | **未上榜** |

两条关键结论：

- **`n` 不是「填格子」的参数，是 NFS 的物理尺度参数。** 邻域半径 ∝ `n^(−1/3)`。
- `d2_shape` 用全云抽对，**与 `n` 无关** → 昨天「外推 n 5000 让 SDD 46.8→44.1」不是 n 的因果，是换了子样的噪声。

### 2.1 本次补读的三条机制（都改了策略）

1. **形状两项都是 count-matched。** `_match_n(A,B)` 把两边都子样到 `min(n_pred, n_true)`，
   `occupancy_dice` 和 `d2_shape` 都在此之后算 → **加 n 对形状分毫无影响**，只影响 NFS。
   所以「顶格 n」这个下法的收益全部来自 NFS（25%），不要再指望它救 ODS。
2. **ODS 的网格分辨率在线上是不足的，所以它部分是「采样密度统计量」。** `occupancy_dice` 返回
   `_dice_voxel_over_nn`（体素边长 ÷ 真值中位 NN），docstring 要求「**comfortably above ~10**」才可读。
   真值 E8.5：体素边长 = 6/16 = 0.375（RMS 单位），NN/RMS = 17.76/254.6 = 0.0698 → **比值 5.4**。
   本地对 E8.75 是 **8.7**。含义：线上 ODS 会被**克隆堆**直接扣分（一堆细胞占同一个体素），
   去重（`--ot-unique`）因此对 ODS 也有效，不只是对 NFS 和 `size_fidelity` 有效。
3. **`de_score` 的分母是「实测 null」，不是超几何。** `score = (raw − chance)/(1 − chance)`，
   `chance` = 用参照自身表达量排序能拿到的重叠（取上/下两个方向的较好者）。
   `copy_last`（pred = ref）的 Δ 为 0 → 直接判 0 → skill 50。所以**表达两项的 skill ≈ 50 + 50·score**，
   我们线上 `de_score` 63.0 ⇒ score ≈ 0.26，天花板 1.0 ⇒ 这一项单独还有 **+37 skill = +4.6 总分**的空间。
   但 §4.3 说明：真 E8.5 的 RNA 也拿不到这块空间，跨模态误差比信号大。

## 3. 用泄漏的真值标定密度

`common/shape_metrics.py::size_fidelity` 的 docstring 里有一张心脏各阶段表（这是官方为论证指标设计写进去的，随 `pip install veckit` 发放）：

| 阶段 | RMS | 中位 NN（4000 子样） | 我们的实测 RMS | 本地实测 NN1@4000 | 密度轮廓 `NN·4000^(1/3)/RMS` |
|------|-----|----------------------|----------------|-------------------|------------------------------|
| E8.25 | 355.6 | 17.10 | 354.1 ✓ | **19.17** | 0.859 |
| **E8.5（held-out）** | **254.6** | **17.76** | — | — | **1.107** |
| E8.75 | 216.3 | 16.27 | 216.9 ✓ | **14.56** | 1.066 |
| E9.5 | 335.2 | 17.17 | 335.0 ✓ | **18.51** | 0.877 |
| **E10.5（held-out）** | **439.9** | **16.83** | — | — | **0.607**（原稿写 0.934，算术笔误） |
| E12.5 | 511.5 | 17.06 | — | — | — |

「本地实测」列是用官方 `median_nn_distance` 跑 `data/` 里同阶段云得到的，与 docstring 的 17.10 / 16.27 / 17.17 只差 8–12%（同一批云、子样噪声）。
**所以这张表就是我们手里的这批数据，泄漏值可以直接当标定目标用。**
⚠️ 量法：官方是**先子样 4000、再在这 4000 个点上建 kNN**；如果先从全云找最近邻，数字会小 1.7 倍（E8.75：8.70 vs 14.56），别用错。

三个用途：

1. **交叉验证我们的尺度锁**：线上 TSR 二分反推的 255 / 438，对上了 254.6 / 439.9。RMS 这块确实做完了。
2. **E8.5 的密度轮廓 1.107 比 E8.75 的 1.066 还高**，而 E8.25 只有 0.859 → 真 E8.5 的 FOV 收窄程度**已经超过时钟 w=0.5 的线性插值**，和「RMS 255 落在 log 路径 w=0.67」一致，也和胚胎代理上「轴比的有效权重 ≈0.85–1.0、远大于时钟 0.4」一致。**心脏几何该往 E8.75 那一侧多走。**
3. **算出邻域半径该是多少**（假设 `n_true ≈ n_max`，即官方上限就是真值细胞数）。
   换算关系从三个 released 云实测：`NN15@all / NN1@4000` = **1.12**（E8.25, n=58716）、**1.40**（E8.75, n=24826）、**1.17**（E9.5, n=53742），再按 `n^(−1/3)` 折到上限的 n：

| 榜 | 真值 NN15 窗口 | 我们现在 | 拉到上限后 | 判定 |
|----|----------------|----------|------------|------|
| 心脏插值 E8.5 | **22–28** | **39.5**（n=5000） | **23.3**（n=17616） | 顶格刚好进窗口（1.4 倍 → 1.0 倍） |
| 心脏外推 E10.5 | **18–24** | **70.9**（n=5000） | **39.0**（n=25179） | 3.1 倍 → **仍差 1.6–2.1 倍，顶格也补不满** |

外推是 NFS 卡在地板 51.0 的直接原因：把 E9.5 拉伸 1.307 倍后只交 5000 个细胞，每个细胞的 15 邻域覆盖了真值 3 倍大的物理范围，pseudobulk 被过度平滑。
但**别指望外推 NFS 追平心脏插值**：真值 E10.5 的细胞间距和 E9.5 几乎一样（16.83 vs 18.51），RMS 却大 1.31 倍 —— 那要求 2 倍以上的细胞数，上限 25179 给不了。
所以外推**只花 1 格**（n 顶满就收手），也不要花格子去测 n=12000 中点：我们还在「细胞不够」的一侧，曲线单调，中点没有信息量。

**一个必须记住的机制：NFS 对整体缩放完全不变。** `_knn_neighborhood_pb` 用的是 kNN 的**秩**（`NearestNeighbors(k).fit(coords).kneighbors(coords)`），均匀缩放坐标不改变「谁的 15 个最近邻是谁」，pseudobulk 一模一样。两个推论：

- `scale_log_ratio`（RMS 锁）和 NFS **不冲突**，RMS 锁到真值不花 NFS 一分钱。
- 外推的 NFS **不能靠把云缩小来救**（缩了 TSR 掉、NFS 一动不动）。剩下的旋钮只有 `n`（已顶格）和点云的相对疏密结构。
- 顺带：`_knn_neighborhood_pb` **不剔除自身**（`morans_I_profile` 才剔），所以 pseudobulk = (自己 + 14 个邻居)/15。克隆堆里细胞的 14 个邻居就是它自己的副本 → pseudobulk 退化成单细胞值、完全不平滑，这就是「截 FOV + 大 n 不去重」NFS 爆到 0.1252 的机制。

### 3.1 NFS 对 n 的敏感度（本次新测，决定「n 该不该顶格」）

把真值云自己子样当预测（表达和几何都完美，**只有 n 不对**），直接调官方 `neighborhood_mmd`：

**n 不足一侧**（真值 = released E8.75，n=24826；预测 = 它的子样）：

| pred_n | 1000 | 2000 | 3000 | 5000 | 8000 | 12000 | 17616 | 24826 |
|--------|------|------|------|------|------|-------|-------|-------|

**n 过头一侧**（真值 = E8.75 的子样，预测 = 更全的云）：

| truth_n | pred_n | 倍数 | NFS_raw |
|---------|--------|------|---------|

### 4.2 本轮真正的杠杆：丢弃式截 FOV（`--crop-keep`）+ 径向保 CDF 的轴比恢复

§4.1 的 C 是把全部 n 个细胞用 OT **搬进**核心区（`--crop-to-rms`）：外周细胞的表达被搬到中心、`(X,xyz)` 耦合被拆，NFS 付钱（0.0635）。官方 `size_fidelity` 的 docstring 证明心脏各阶段 RMS 的差别是**成像视野（FOV）不同**、不是组织在缩（NN 恒定 16.3–17.8、RMS 却 216–512 摆动）。所以 E8.5 的真值是**同一块组织的更窄视野**，正确做法是把左锚外周**直接丢掉**、让每个细胞留在自己坐标上 —— 这就是 `--crop-keep`（先按 `--over-alloc` 超配、再按半径拒绝）。

**真细胞标定（只在真细胞上做，不碰提交）**：把真 E8.25 按半径拒绝裁到目标 RMS 再放大，能在 2–5% 内复现真 E8.75 的细胞间距；最佳裁点在锚点 RMS 的 t≈1.10–1.20，之后必须**恢复轴比**，d2 从当前文件的 0.054 降到 0.0032。
